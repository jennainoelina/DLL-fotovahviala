# Fotovahviala Website

Fotovahviala on valokuvausyritykselle toteutettu verkkosivusto, jonka tarkoituksena on esitellä palvelut, hinnasto, portfolio sekä tarjota asiakkaille helppo yhteydenottokanava.

Projektin aikana toteutettiin sekä käyttöliittymä (frontend) että palvelinpuoli (backend). Sivusto on responsiivinen ja toimii sekä tietokoneella että mobiililaitteilla.

## Ominaisuudet

- Etusivu
- Portfolio
- Hinnasto
- Yhteystiedot
- Yhteydenottolomake
- Kuvien hallinta
- Kirjautumissuojattu ylläpitonäkymä
- Kuvien lataaminen palvelimelle
- Kuva-arkiston ZIP-lataus
- Responsiivinen ulkoasu

## Teknologiat

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Nodemailer
- Multer

## Kehitysprosessin opit

Projektin aikana suurimmat haasteet liittyivät backend-kehitykseen, palvelimen asetuksiin ja
frontendin sekä backendin väliseen tiedonsiirtoon. Aluksi backendin toiminta ja eri tiedostojen 
väliset yhteydet olivat vaikeita hahmottaa, mutta projektin edetessä ymmärrys kasvoi huomattavasti. 
Erityisesti virheiden etsiminen, ongelmanratkaisu ja järjestelmällinen testaus kehittivät 
ohjelmointiosaamista merkittävästi.
